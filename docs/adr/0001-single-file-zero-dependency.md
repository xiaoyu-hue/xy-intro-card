# ADR-0001: 单文件零依赖架构

## 状态
采纳（Accepted） · 2026-09

## 背景

个人介绍卡需要被**频繁分享、收藏、嵌入**，且目标用户（俱乐部主理人 / 成员）多为非技术背景。任何「需要 npm install / 起服务 / 联网」的形态都会立刻抬高使用门槛。

## 决策

整个生成器与每张导出卡均为**单个 HTML 文件**，样式与脚本内联，资源（图标 SVG、头像 base64）内嵌，**零外链、零构建、零依赖**。

## 权衡

- 备选 A：拆分为 HTML + CSS + JS 多文件 → 更易维护，但分享 / 嵌入时要打包多文件，对非技术用户不友好。**否决**。
- 备选 B：用 React / Vite 做工程化 → 开发体验好，但引入构建与依赖，违反「零构建」底线，且卡片无法脱离构建产物独立打开。**否决**。

接受代价：单文件较长、样式与逻辑耦合度高、难以跑自动化单元测试（见 `TESTING.md` 以 Node 逻辑校验 + 截图替代）。

# 决策审查清单（DECISION_REVIEW）

> 任何**发版**或**不可逆操作**（公开仓库、删除文件、覆盖代码、付费服务）前，必须逐条过此清单。

## 决策三问

1. **为什么做？** —— 动机是否来自真实用户需求，而非技术自嗨？
2. **有没有更简？** —— 是否存在零依赖 / 更少代码的等价方案？
3. **错了能回退吗？** —— 若不可逆，是否已获用户明确同意并备好回退路径？

## 五层追问

- 第一层：这个功能**用户真的会用到**吗？有没有证据？
- 第二层：不做会怎样？**最小代价**是什么？
- 第三层：实现是否**违反底线**（零依赖、零构建、不收集数据）？
- 第四层：对**已有卡片 / 文档 / 示例**的兼容性影响？
- 第五层：要不要先**小步验证**再全量？

## 发版前必过项

- [ ] 已过决策三问
- [ ] 已过五层追问
- [ ] 不可逆操作已获用户同意
- [ ] 已对照 `DOC_SYNC.md` §4 完成发布前验证
- [ ] 已记录相关 ADR（若有架构级决策）

## 红线提示

- 引入前端框架 / 打包器 → 违反零构建底线，须先过本清单并记 ADR。
- 外链第三方资源 / 收集用户数据 → 违反零依赖 / 隐私底线，默认拒绝。

# 产品需求文档（PRD）

> 定位、功能边界、字段规范与验收标准。非技术决策者与开发者都应以此为准。

## 1. 产品定位

一套**可复用的个人介绍名片生成器**，给**任意俱乐部 / 团队**的成员制作统一风格的个人介绍卡。

- **不是**某个俱乐部的私有物：XY俱乐部 仅为默认演示案例。
- 与 [`xy-club`](https://github.com/xiaoyu-hue/xy-club)（俱乐部官网模板）是同一「XY 系列」的两件配套工具：官网承载整体站点，本工具给成员做个人名片。

## 2. 目标用户

- **主理人 / 运营**：非技术背景，需要零代码、批量给成员出名片。
- **成员**：拿到一张可分享、可收藏的 HTML 卡片。

## 3. 核心功能

| 功能 | 说明 | 优先级 |
|---|---|---|
| 两种字段模式 | 「人设卡」与「通用名片」一键切换 | P0 |
| 内容填写 | 表单驱动，实时预览右侧手机效果 | P0 |
| 主题色 | 落日金 / 深海蓝 / 极光紫 / 晨雾白 | P0 |
| 头像上传 | 自动压缩，避免大图卡死 | P0 |
| 一键导出 | 下载独立 HTML 卡片，零依赖 | P0 |
| 移动端适配 | 多断点、刘海屏安全区 | P1 |
| 性能降级 | 帧率不足 / 减弱动态 / 后台暂停 | P1 |

## 4. 字段规范

详见 [`FIELDS.md`](FIELDS.md)。两种模式字段互不耦合，导出时按 `mode` 选择模板。

## 5. 验收标准

- [ ] 打开生成器无需联网、无需服务器即可使用
- [ ] 切换两种模式，预览与导出字段正确
- [ ] 四种主题色在预览与导出卡均正确注入（含光斑、文字深浅）
- [ ] 上传 2400×2400 图片，预览不卡死，导出卡体积约 10KB 级
- [ ] 导出卡在独立浏览器（含手机）打开，视觉与预览一致
- [ ] 所有用户输入经转义，无 XSS
- [ ] 未传头像时显示「主题色 + 首字」占位

## 6. 非目标（明确不做）

- ❌ 后端存储 / 多人在线协作编辑
- ❌ 服务端鉴权 / 账号体系
- ❌ 复杂动画 / 3D / 视频背景
- ❌ 引入前端框架 / 打包器（保持零构建零依赖）

## 7. 成功指标

- 一名完全不懂代码的成员，5 分钟内独立产出一张可分享名片。
- 同一俱乐部全员名片视觉风格统一。

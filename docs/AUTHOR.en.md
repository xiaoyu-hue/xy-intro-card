## Collaboration style

- Goal & scope first: confirm requirements before coding; ask upfront when info is missing; no mid-way guessing.
- Break big tasks into verifiable small steps; ship one runnable minimal version at a time.
- Tech choices come with rationale and need approval; implementation details can be autonomous.
- Irreversible ops (delete files, overwrite code, paid services, public release) require explicit consent.
- State uncertainty honestly; never fabricate library / API / version / config names.
- Proposals must explain trade-offs and proactively surface defects and alternatives.

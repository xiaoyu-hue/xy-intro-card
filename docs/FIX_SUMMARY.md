## 详细修复内容

### ✅ 修复 1: 拆分 setup() 函数

**改动**: 将 60 行的 `setup()` 函数拆分为 3 个子函数

```javascript
// 拆分前
function setup() {
  // 60 行代码...
}

// 拆分后
function initFormFields() { /* 表单初始化 */ }
function bindEvents() { /* 事件绑定 */ }
function startPreview() { /* 预览启动 */ }
function setup() {
  initFormFields();
  bindEvents();
  startPreview();
}
```

**收益**:
- setup() 从 60 行降至 12 行
- 每个子函数职责单一，便于测试和维护
- 保持向后兼容，外部 API 无变化

### ✅ 修复 3: 添加 ARIA role 属性

**新增内容**:

| 位置 | 改动 | 用途 |
|------|------|------|
| 模式切换按钮 | 添加 `role="tab"` + `tablist` | 屏幕阅读器识别为标签页 |
